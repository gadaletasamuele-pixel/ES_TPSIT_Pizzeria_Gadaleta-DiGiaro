# ES_TPSIT_Pizzeria_Gadaleta-Digiaro
##### Progetto di gruppo: Gadaleta Samuele, Digiaro Giuseppe

Il progetto che affronteremo è quello di un'applicazione web per una pizzeria. In particolare,
realizzeremo un menu completo da tre sezioni.

##### Il nostro gruppo è composto da 2 persone:
Il project manager / Sviluppatore A e Sviluppatore B.
Ogni sviluppatore deve aggiungere delle portate nel proprio menù
- Sviluppatore Gadaleta (Project manager / Sviluppatore A) : assegnato al menù pizze e bevande;
- Sviluppatore Digiaro (Sviluppatore B) : assegnato al menù dolci e home.

##### Cenni teorici
### GITHUB

GitHub è una piattaforma online (un servizio cloud) che serve a ospitare, gestire e condividere progetti di programmazione.
Puoi immaginarlo come una combinazione tra un archivio cloud (come Google Drive o Dropbox) pensato specificamente per il codice e un social network per sviluppatori.
Le caratteristiche principali di GitHub

Lavoro di Squadra (Collaboration): Permette a più persone sparse in tutto il mondo di lavorare sullo stesso progetto contemporaneamente senza sovrascrivere il lavoro degli altri. Ognuno può proporre delle modifiche (Pull Request) che il creatore del progetto può esaminare e decidere se integrare.

Backup e accessibilità nel cloud: Salvando il tuo codice su GitHub (in spazi chiamati repository), non rischi di perderlo se si rompe il computer e puoi scaricarlo e lavorarci da qualsiasi altro dispositivo.

Open Source: Moltissimi progetti nel mondo sono pubblici e accessibili a chiunque. Chiunque può studiare il codice di altri, segnalare bug o contribuire a migliorarlo.
